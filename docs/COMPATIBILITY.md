## 已知不兼容

- `collection.anki21b`：Anki 2.1.50+ 默认导出的 zstd 库，设备没有 zstd，提示用户重新导出并勾选「支持旧版 Anki」。
- 模板 JavaScript / CSS：不执行；依赖 JS 动态展开的模板只按静态字段显示。
- 图片、音频：不显示/不播放。
- 超大包：只读前 4 MB 前缀取数据库；如果数据库本身在 4 MB 之后，读不到。
- 自定义学习步骤：与默认 1 分钟 / 10 分钟差异很大时按默认近似。

## 回归清单

2. `60__.apkg`：标题行、17 行挖空、逐行点开、显示全部、评分。
3. `blank.apkg`：正面和答案面都不为空。
4. `2025.apkg`：不崩溃，牌组和配额正常。
5. `image_by_ChatGPT.apkg`：文字卡能学，不因大包被拒绝。
6. 两个 apkg 来回切换：各自进度保留，不从头开始。
7. 退出应用再进入：当天进度和已学卡状态还在。
